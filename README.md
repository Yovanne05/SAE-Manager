# SAE Manager

## 📝 Description

Application web de gestion de projets académiques avec interfaces distinctes pour professeurs et étudiants.

## ✨ Fonctionnalités principales

- **Espace Professeur** :
  - Création/gestion des projets et groupes
  - Évaluation des travaux étudiants
  - Tableau de bord de suivi

- **Espace Étudiant** :
  - Dépôt de fichiers et rendus
  - Consultation des ressources
  - Visualisation des notes

## 🛠️ Stack Technique

### Frontend
- Bootstrap : Interface responsive
- JavaScript : Interactions dynamiques

### Backend
- PHP : Logique métier
- MySQL : Base de données relationnelle

### Méthodologie
- Architecture MVC
- Gestion Agile (Trello)

## 🚀 Déploiement
1. Importer le schéma SQL
2. Configurer les accès DB dans Connexion.php
3. Héberger sur un serveur Apache/PHP

## 📊 Bilan Technique

- **Durée** : Développé en 3 mois
- **Points forts** :
  - Architecture MVC bien structurée
  - Séparation claire des interfaces professeurs/étudiants
  - Expérience complète de gestion de projet Agile

- **Challenges relevés** :
  - Gestion fine des droits d'accès
  - Sécurisation des formulaires (protection CSRF, validation des inputs)
  - Optimisation des requêtes SQL

- **Compétences acquises** :
  - Modélisation de base de données
  - Développement full-stack (PHP/JS)
  - Gestion d'un projet collaboratif
